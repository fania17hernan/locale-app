The problem
Trip planning is fragmented and exhausting

"The problem I'm trying to solve is making planning trips seamless and less hectic. To plan a trip today I have to juggle multiple tools — ChatGPT or Claude for ideas, Google or Apple Maps for navigation, spreadsheets for logistics, group chats for collaboration. The result is often fragmented and frustrating for the planner, which is always me."

The goal: consolidate all those planning tools into one personalized, interactive hub — with an AI-powered itinerary builder that handles pre-trip planning, real-time suggestions, local tips, and shared planning so the planner feels organized and excited about the trip, not anxious about tracking everything.

Group travel is one of the most logistically complex things people do together — and yet the tools haven't really caught up. What exists today falls into two camps:

🧳 Full-scale travel apps (TripIt, Wanderlog, TripAdvisor)
Powerful but heavy. Require accounts, often require imports from email confirmations, and the collaboration features are buried behind paywalls or too complex for casual group trips. They're built for the solo frequent traveler, not a group of friends going to Disney together.
📋 DIY tools (Google Docs, Notion, Notes)
Flexible but unstructured. Everyone's editing the same doc, formatting breaks, there's no checklist logic, no itinerary structure, and sharing requires everyone to have an account or remember a link. It works but it doesn't feel like a product.
The opportunity
What Locale is trying to be

Locale is a lightweight group trip planner that combines the structure of a travel app with the simplicity of sharing a link. No accounts. No app store. No friction.

The goal is to answer three questions every group traveler asks:

📋 Are we ready?
Trip-specific checklist — documents, bookings, packing. Tracks prep progress right on the dashboard card.
📅 What's the plan?
Day-by-day itinerary with activities, restaurants, and booking links — generated by AI or built manually.
🔗 Does everyone know?
One tap shares the full trip as a link. Recipients open it, add it to their app, and see the same plan.
Technical approach
Why a PWA for the proof of concept

Before investing in native iOS/Android development or a full backend, Locale is being validated as a Progressive Web App (PWA) — a website that behaves like an app on your phone.

A PWA can be installed on your home screen, works offline, loads instantly, and is indistinguishable from a native app for most everyday tasks — at a fraction of the build cost.

The PWA approach lets us validate the core concept — does this actually solve the group planning problem? — before committing to native development. If the answer is yes, a native app or backend sync layer gets added in Phase 2.

Current limitation
The one big caveat

Right now, trips are stored on your device only. If you share a trip link with someone, they get a copy — but changes you make afterwards don't sync to them automatically. You'd re-share the link to update them. This is a known limitation that a backend database solves in Phase 2.

🔵 Coming soon (Phase 1 polish)

1
Role-aware onboarding
Separate flows for trip Creators (need API key) vs. Viewers (receiving a shared trip, should never see the API key prompt).
2
Entry requirements via dedicated API
Currently baked into demo trips only. Move to Travel Buddy AI (free tier) so every trip gets live visa/entry data automatically — no API key needed.
3
Better date picker UX
Replace browser-native date inputs (which vary wildly by device) with Flatpickr for a consistent, on-brand experience. Add calendar icon.
4
Open Graph link previews
Shared links currently preview as just "Locale — Your trips, beautifully kept." Should show trip name, destination, and dates.
5
📧 Confirmation email parsing
Paste or upload a booking confirmation (flight, hotel, tour, restaurant) and the AI extracts the key details — dates, times, confirmation numbers, addresses — and adds them directly to your trip. Similar to how Apple Calendar pulls events from confirmation emails, but inside Locale so everything lands in the right trip automatically.

🟣 Phase 2 — Future features

6
Real-time trip sync
Backend database (Supabase) so all group members see the same live trip — no need to re-share after every update.
7
User accounts + trip ownership
Login so your trips follow you across devices. Role-based access: organizer, collaborator, viewer.
8
Push notifications
Check-in reminders 24hrs before flights. Itinerary updates when the organizer changes the plan.
9

Comment on specific days or activities. Keep the "where are we meeting?" conversation inside the trip.
10
Native iOS + Android app
Once the PWA POC validates the concept, wrap in a native shell for App Store / Play Store distribution.
11
Booking integrations
Connect directly to OpenTable, Viator, and GetYourGuide so "Book now" badges actually book — without leaving the app.

v0.2
May 31, 2026

✨ New features

Feature
Drag-to-reorder itinerary items — Activities and restaurants within a day can now be reordered by dragging the ⠿ handle. Order is saved automatically.
Feature
City auto-fills country — Typing a recognized city in the new trip form (90+ cities worldwide) automatically fills in the country code and flag. No manual entry needed.
Feature
Booking buttons on checklist — Checklist items with a booking URL now show a tappable button: "🎟️ Book tickets →" for venues or "🍽️ Book reservation →" for restaurants. Clicking the button doesn't accidentally check off the item.

🐛 Bug fixes

Fix
iPhone auto-zoom on inputs — Safari was zooming in when tapping form fields. All inputs now set to 16px minimum.
Fix
Keyboard hiding navigation buttons — On iPhone, the soft keyboard was pushing Back/Preview buttons off screen during trip creation. Fixed with 100dvh + dynamic viewport layout.
Fix
Invalid date ranges allowed — End date could be set before start date with no warning. Now validated inline with an error message, and end date auto-suggests +1 day from start.
Fix
Wrong destination flag — Trips were showing the passport country flag instead of the destination country flag next to city names.
Fix
City name capitalization — "ZUrich" or "pARIS" would display as typed. Now normalized to title case on input.
Fix
Text truncation in itinerary cards — Hotel name and address were being clipped mid-word in the day view hotel strip.
Fix
Duplicate share buttons — Two nearly identical share buttons existed, one of which sent unformatted plain text instead of a tappable trip link. Duplicate removed.
Fix
Traveler avatar initials showed no names — Hovering (desktop) or long-pressing (mobile) now reveals the full traveler name in a tooltip.
Fix
Delete button had redundant text label — Now shows icon only (🗑) for a cleaner header.
